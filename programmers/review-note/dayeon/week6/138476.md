## [`프로그래머스`: `귤 고르기`]

### 사용했던 방식 및 알고리즘
- `HashMap`을 사용해서 귤 크기별 개수를 세었다.
- `map.getOrDefault()`를 사용해서 같은 크기의 귤이 몇 개 있는지 누적했다.
- `map.values()`로 귤 크기별 개수만 꺼냈다.
- `stream()`과 `sorted(Comparator.reverseOrder())`를 사용해서 개수를 내림차순으로 정렬했다.
- 개수가 많은 귤 종류부터 선택하면서 `k`개를 채웠다.

### 해결이 안 됐던 점
- 왜 귤 크기가 아니라 귤 개수를 기준으로 정렬하는지 헷갈렸다.
- `HashMap<Integer, Integer>`에서 key와 value가 각각 무엇을 의미하는지 헷갈렸다.
- `getOrDefault()`가 어떤 역할을 하는지 헷갈렸다.
- `map.values()`가 무엇을 꺼내는지 헷갈렸다.
- `stream()`, `sorted()`, `Comparator.reverseOrder()`, `collect()` 흐름이 어려웠다.
- `k -= count`와 `answer++`가 왜 같이 사용되는지 이해하기 어려웠다.

### AI 및 구글링에서 알려준 방식 및 알고리즘
```java
HashMap<Integer, Integer> map = new HashMap<>();

for (int size : tangerine) {
    map.put(size, map.getOrDefault(size, 0) + 1);
}

List<Integer> counts = map.values().stream()
        .sorted(Comparator.reverseOrder())
        .collect(Collectors.toList());

int answer = 0;

for (int count : counts) {
    k -= count;
    answer++;

    if (k <= 0) break;
}

return answer;
