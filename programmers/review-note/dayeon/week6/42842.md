## [`프로그래머스`: `카펫`]

### 사용했던 방식 및 알고리즘
- `yellow`의 약수를 이용해서 노란색 영역의 가로와 세로 후보를 찾았다.
- `for`문으로 `1`부터 `yellow`까지 돌면서 노란색 가로 후보 `i`를 검사했다.
- `yellow % i == 0`이면 `i`를 노란색 가로로 사용할 수 있다고 판단했다.
- 노란색 세로는 `yellow / i`로 구했다.
- 노란색 가로가 세로보다 크거나 같은 경우만 확인했다.
- 노란색 영역을 갈색 테두리로 감쌌을 때 필요한 갈색 개수를 계산했다.
- 계산한 갈색 개수 `brown1`이 입력받은 `brown`과 같으면 전체 카펫 크기를 반환했다.

### 해결이 안 됐던 점
- 왜 `yellow`의 약수를 이용해야 하는지 이해하기 어려웠다.
- `yellow % i == 0`이 어떤 의미인지 헷갈렸다.
- `int h = yellow / i`가 왜 노란색 세로가 되는지 헷갈렸다.
- 갈색 개수를 `(i * 2) + (h * 2) + 4`로 계산하는 이유가 어려웠다.
- 정답을 `i + 2`, `h + 2`로 반환하는 이유가 헷갈렸다.
- 노란색 영역의 크기와 전체 카펫의 크기를 구분하는 것이 어려웠다.

### AI 및 구글링에서 알려준 방식 및 알고리즘
```java
for (int i = 1; i <= yellow; i++) {
    if (yellow % i == 0) {
        int h = yellow / i;

        if (i >= h) {
            int brown1 = (i * 2) + (h * 2) + 4;

            if (brown1 == brown) {
                return new int[]{i + 2, h + 2};
            }
        }
    }
}

```
알고리즘 설명
이 문제는 갈색 테두리 안에 노란색 영역이 있는 카펫의 전체 가로, 세로 길이를 구하는 문제다.
노란색 영역은 가운데에 있는 직사각형이다.
갈색 영역은 노란색 영역을 한 줄 두께로 감싸는 테두리다.

**알고리즘 설명**

예시:

```text
BBBBBB
BYYYYB
BYYYYB
BYYYYB
BBBBBB
```
노란색 가로 = 4
노란색 세로 = 3
yellow = 4 * 3 = 12

- 가로 * 세로 = 전체 개수 형태의 문제에서는 약수를 이용해 가로와 세로 후보를 찾을 수 있다.
- `area % width == 0`이면 `width`는 가능한 가로 후보이다.
- 이때 세로는 `area / width`로 구한다.

갈색 개수는 다음 코드로 계산한다.
`int brown1 = (i * 2) + (h * 2) + 4;`
```
노란색 영역이 가로 i, 세로 h일 때 갈색 테두리는 다음처럼 나뉜다.
위쪽 갈색: i개
아래쪽 갈색: i개
왼쪽 갈색: h개
오른쪽 갈색: h개
모서리 갈색: 4개

그래서:
갈색 개수 = 위쪽 + 아래쪽 + 왼쪽 + 오른쪽 + 모서리
갈색 개수 = i + i + h + h + 4
갈색 개수 = (i * 2) + (h * 2) + 4

예를 들어:
노란색 가로 = 4
노란색 세로 = 3
이면:

brown1 = (4 * 2) + (3 * 2) + 4
brown1 = 8 + 6 + 4
brown1 = 18
계산한 갈색 개수와 입력받은 갈색 개수가 같으면 정답이다.

if (brown1 == brown) {
return new int[]{i + 2, h + 2};
}
```
전체 카펫은 노란색 영역 바깥에 갈색 테두리가 한 줄 붙은 모양이다.
따라서:
전체 가로 = 노란색 가로 + 왼쪽 갈색 1칸 + 오른쪽 갈색 1칸
전체 가로 = i + 2

전체 세로 = 노란색 세로 + 위쪽 갈색 1줄 + 아래쪽 갈색 1줄
전체 세로 = h + 2
그래서 반환값은 다음과 같다.\
`return new int[]{i + 2, h + 2};`\

핵심 정리:
1. yellow로 만들 수 있는 직사각형의 가로, 세로를 찾는다.
2. 그 노란색 직사각형을 갈색 테두리로 감쌌을 때 brown 개수가 맞는지 확인한다.
3. brown 개수가 맞으면 전체 가로, 세로는 노란색 가로, 세로에 각각 2를 더한 값이다.
