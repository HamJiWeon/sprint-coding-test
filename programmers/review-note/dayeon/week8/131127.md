## [`프로그래머스`: `할인 행사`]

### 사용했던 방식 및 알고리즘
- `HashMap`을 사용해서 원하는 상품과 개수를 저장했다.
- `for`문을 사용해서 가입 가능한 시작 날짜를 하나씩 확인했다.
- 각 시작 날짜마다 10일 동안의 할인 상품 개수를 `HashMap`에 저장했다.
- `Map.equals()`를 사용해서 원하는 상품 목록과 10일 할인 상품 목록이 같은지 비교했다.

### 해결이 안 됐던 점
- `HashMap`에 상품 이름과 개수를 어떻게 저장하는지 헷갈렸다.
- `getOrDefault()`가 어떤 역할을 하는지 이해하기 어려웠다.
- `start <= discount.length - 10` 조건이 왜 필요한지 헷갈렸다.
- `windowMap`과 `wantMap`의 차이가 헷갈렸다.
- `Map.equals()`가 무엇을 기준으로 같은지 판단하는지 헷갈렸다.

### AI 및 구글링에서 알려준 방식 및 알고리즘
```java
Map<String, Integer> wantMap = new HashMap<>();

for (int i = 0; i < want.length; i++) {
    wantMap.put(want[i], number[i]);
}

for (int start = 0; start <= discount.length - 10; start++) {
    Map<String, Integer> windowMap = new HashMap<>();

    for (int j = start; j < start + 10; j++) {
        windowMap.put(discount[j], windowMap.getOrDefault(discount[j], 0) + 1);
    }

    if (windowMap.equals(wantMap)) {
        answer++;
    }
}
```
- 알고리즘 설명
  wantMap은 내가 원하는 상품과 필요한 개수를 저장하는 HashMap이다.

```
want = ["banana", "apple"]
number = [3, 2]

wantMap = {
  banana=3,
  apple=2
}
```
- windowMap은 특정 시작 날짜부터 10일 동안 할인하는 상품과 개수를 저장하는 HashMap이다.

- 예시:
  discount = ["banana", "apple", "banana", ...]

```
start = 0이면 discount[0]부터 discount[9]까지 확인한다.
start = 1이면 discount[1]부터 discount[10]까지 확인한다.
```
getOrDefault()는 해당 상품이 이미 있으면 기존 개수를 가져오고, 없으면 기본값 0을 사용한다.
windowMap.getOrDefault(discount[j], 0) + 1
뜻:
현재 상품의 기존 개수 + 1

```
예시:
banana를 처음 만나면: 0 + 1 = 1
banana를 또 만나면: 1 + 1 = 2
Map.equals()는 두 Map의 key와 value가 모두 같을 때 true를 반환한다.
```
```
예시:
wantMap   = {banana=3, apple=2}
windowMap = {banana=3, apple=2}
```
결과: true
wantMap   = {banana=3, apple=2}
windowMap = {banana=3, apple=1}

결과: false
따라서 모든 10일 구간을 검사하면서 windowMap과 wantMap이 같으면 해당 날짜는 정답이 된다.
조건에 맞는 날짜를 찾을 때마다 answer++를 하고, 마지막에 answer를 반환한다.
